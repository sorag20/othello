# Archive: distilled-NN CodinGame attempt (superseded)

This is an earlier, complete CodinGame "Othello" submission attempt (built
2026-08-24, before the current `../othello_bot.cpp` minimax approach):
a PUCT MCTS search (`cpp/search.hpp`) guided by `TinyOthelloNet`, a small
(~16k parameter) CNN distilled from the production AlphaZero model
(`backend/models/weights/model.pt`) via `train/distill.py`, with a
hand-written C++ forward pass (`cpp/evaluator.hpp`) and the trained weights
embedded as a base64 blob (`cpp/dnn_weight.hpp`, generated by
`export_weights.py` from `weights/tiny_model.pt`). `build/submission.cpp`
is the fully assembled single-file version of this approach, ready to
paste into CodinGame's Web IDE.

It's kept here for reference/comparison rather than deleted. The
distillation results were mediocre (`train/distill_run.log`: ~45% policy
top-1 agreement with the teacher, value MAE 0.38 on a [-1, 1] scale) —
part of the motivation for the move to a classical bitboard alpha-beta
minimax engine instead, which doesn't depend on a trained model at all and
fits CodinGame's tight 150ms/turn budget more predictably.

Nothing here is wired into the current submission; `cpp/board.hpp` and
`cpp/common.hpp` use the same bitboard layout convention (bit index =
`row*8+col`, row 0 = top) as `../othello_bot.cpp`, if any of this ever
needs to be revisited.
